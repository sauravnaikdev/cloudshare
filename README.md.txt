# ☁️ CloudShare

### Backend
- Java 21
- Spring Boot
- Spring Security
- JWT
- DynamoDB
- AWS S3
- Kafka

### Frontend
- React
- TypeScript
- Tailwind CSS
- Axios

### DevOps
- Docker
- Kubernetes
